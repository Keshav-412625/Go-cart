# ReduxStore

ReduxStore ek responsive React-based storefront application hai jisme users products browse, filter aur cart mein add kar sakte hain.

## Features

- React 18 based user interface
- Redux Toolkit ke through global state management
- Product category filtering
- Minimum aur maximum price filtering
- Light/Dark theme toggle
- Shopping cart functionality
- Cart items remove aur clear karne ka option
- Infinite scrolling ke saath Load More support
- Responsive design for desktop aur mobile screens
- Product cards with category, price aur emoji-based icons

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React 18
- Redux Toolkit
- React Redux
- Babel Standalone
